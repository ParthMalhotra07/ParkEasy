# ParkEasy – Smart Parking Management System

ParkEasy is a web-based application designed to simplify and automate the process of discovering, booking, and managing parking spaces. The system provides a friendly interface for users to find parking spots in real-time while offering administrators powerful tools to manage slots, monitor usage, and maintain records efficiently.

##  Features

### User Features
- **User Registration & Login** – Secure authentication using role-based access.
- **Search Parking Spots** – Locate nearby available slots with live availability.
- **Book & Manage Parking** – Reserve slots, view bookings, and manage your parking history.
- **Responsive UI** – Works smoothly across desktop and mobile devices.

### Admin Features
- **Dashboard** – Overview of total users, active bookings, available slots, and system statistics.
- **Slot Management** – Add, edit, and delete parking slots.
- **User Management** – View, update, or remove users as needed.
- **Booking Monitoring** – Track current bookings, occupancy status, and analytics.

### Technical Features
- Modular code structure with separation of frontend, backend, and configuration.
- Scalable folder structure for easy project extension.
